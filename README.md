## 🚀 Selected Projects & Research

### [District Air Scope](https://github.com/siddhant3895/district-air-scope)
**Creator · Environmental Data Systems · React, TypeScript, FastAPI**

An India-focused air-quality monitoring platform built around a curated registry of 30 districts. It combines a React/TypeScript frontend with a FastAPI backend for provider ingestion, station-level CPCB NAQI evaluation, and district snapshots with source attribution, freshness, coverage, and data-quality caveats.

The displayed district value is a project-defined composite derived from reviewed monitoring stations, not an official CPCB administrative-district AQI.

### [Socket Peek](https://github.com/siddhant3895/socket-peek)
**Creator · Python · Developer Tooling**

A cross-platform supply-chain network auditor that runs a command behind a logging HTTP/HTTPS proxy and reports the hosts it contacts. It uses a no-TLS-interception design, classifies known and unrecognised destinations, and supports machine-readable output and optional CI gating.

### [Physics Resonance Simulation](https://github.com/siddhant3895/physics-resonance-simulation)
**Independent Computational Research · MATLAB · LaTeX**

A numerical investigation of Tesla's mechanical oscillator and its resonance constraints, using a forced, damped harmonic oscillator model. Includes MATLAB simulations, analytical visualisations, and a 22-page research preprint.

### [ChessMetrics](https://github.com/siddhant3895/chessmetrics)
**Python · Chess Data Analytics**

A PGN analysis pipeline that parses and cleans chess match histories, extracts game metadata, and examines performance patterns against Chess.com computer opponents.
